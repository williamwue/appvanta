# 运行环境比较

完整运行比较现在包含运行前观察到的输入法、声明文件内容、AppOps 和运行时权限。环境在夹具修改前采集；它描述初始状态，不证明运行后全部状态已恢复。

- 输入法记录当前 Android 用户、默认组件及启用列表。
- 文件仅检查 Flow 声明的路径，区分不存在与存在，存在时记录 SHA-256；不会把文件正文写入环境证据。符号链接、非普通文件或无法获取摘要均使采集失败。
- AppOps 记录声明的包和操作在当前用户下的实际模式；不支持的状态（例如 UID 级覆盖）继续明确拒绝。
- 运行时权限比较实际授权值、用户和标志。

环境文件受运行记录中的摘要保护。完整比较会报告以上字段变化；声明夹具却缺少对应环境条目，或条目格式无效，均拒绝通过。旧运行与新运行的采集字段不同也会报告差异；两个未声明相关夹具的旧运行仍可按其已有字段比较。`stepsOnly` 仍只比较步骤，不应作为环境一致性的证明。

本地 API 37 验收：`node scripts/verify-environment-state.mjs emulator-5554`，证据 `.appvanta/runs/environment-state-1790704458017/verification.json`。实际读取 Markor AppOps、输入法，并验证本次独占临时文件的缺失、两种内容摘要；完成后文件删除、租约释放。该验收没有切换输入法或改动 AppOps，不替代其恢复验收。差异判断及无效环境拒绝另有完整运行比较回归测试。

尚未覆盖所有系统设置、其他应用私有数据、多用户切换期间采集或全部 OEM 行为；视觉差异、自动对齐和多设备基线属于独立待办。
